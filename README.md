# BreakTimer 🍅

macOS 菜单栏番茄钟：自定义工作/休息时长，工作结束后弹出柔和的全屏休息提醒，可手动关闭。

## 功能

- 自定义工作时长（5–120 分钟）与休息时长（1–30 分钟），设置自动保存
- 工作结束后自动弹出柔和提醒浮层（毛玻璃卡片 + 暗色蒙版），带休息倒计时
- 浮层可手动关闭：点「完成休息」或按 `Esc`
- 菜单栏实时显示剩余时间（🍅 24:31 / ☕️ 04:12），点击菜单可暂停、跳过、停止
- 可选：休息结束自动开始下一轮 / 启动后自动开始第一轮（默认开）/ 登录自启 / 工作结束前 10 秒轻提示音 / 音效开关
- 开机 → 登录 → 自动开跑 → 工作/休息无限循环，全程无需人工介入
- 休息中可「多歇 2 分」、暂停；支持统计今日完成的轮数
- 可选：登录时自动启动（需以 .app 包运行）
- 提醒浮层不会抢焦点，且能盖在全屏应用之上

## 下载安装（推荐）

到 [Releases](https://github.com/wangxihao/BreakTimer/releases) 下载 `BreakTimer-x.x.x.dmg`：

1. 打开 DMG，把 BreakTimer 拖进 Applications
2. 首次打开：**右键点图标 → 打开 → 再点打开**（应用为 ad-hoc 签名、未公证，直接双击会被 Gatekeeper 拦）
3. 启动后自动开始第一轮工作，菜单栏 🍅 处控制一切

支持 macOS 13+，Apple Silicon 与 Intel 通用。应用未公证，介意的话可自行 `makeapp.sh` 从源码构建。

## 构建与运行

```bash
./makeapp.sh          # 通用二进制（arm64+x86_64）+ .app + DMG + ZIP，产物在 build/
open build/BreakTimer.app
```

开发调试（不打包）：

```bash
swift run             # 菜单栏应用，无 Dock 图标
.build/debug/BreakTimer --self-test   # 无头自测计时引擎（14 项检查，exit 0 = 通过）
```

隐藏启动参数 `--autostart`：启动后立即开始工作，用于调试。

## 使用

1. 启动后出现设置窗口：拖动滑块设定工作/休息时长，按需开关提醒选项
2. 点「开始工作」；窗口可以关掉，应用在菜单栏继续运行
3. 工作结束时屏幕弹出休息提醒；休息结束按设置自动或手动开始下一轮
4. 菜单栏 🍅 图标点开即可控制一切（暂停/跳过/停止/设置/退出）

## 排障

- 提醒卡片行为异常时，查看 `~/Library/Logs/BreakTimer-diag.log`（记录每次阶段流转、浮层显隐与按钮点击）
- 隐藏调试参数：`--diag-speed N`（倒计时加速 N 倍）、`--diag-click N`（自动点击测试）、`--autostart`、`--render-marketing <目录>`
- 休息结束若停在「开始下一轮」卡片，说明关闭了「休息结束自动开始下一轮工作」，点卡片按钮或菜单栏 🍅 → 开始工作即可

## 系统要求

- macOS 13 (Ventura) 或更高
- 登录启动项首次开启时，如系统要求确认，请到 系统设置 → 通用 → 登录项 中允许
